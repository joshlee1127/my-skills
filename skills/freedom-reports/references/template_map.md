# 模板檔案結構 — 自由系統簡報模板_2021.pptx

這份 pptx 有兩層可用資源，用途不同，別搞混：

1. **簡報主版（slide masters / layouts）**：完整的 Office 佈景主題，兩組 master、共約 38 個
   layout（標題投影片、標題及內容、章節標題、比較、兩個內容、各種圖文版面…）。這些是「空的」，
   透過 `python-pptx` 的 `prs.slides.add_slide(layout)` 就能生出全新的一頁，套用自由系統的
   配色、字型、頁尾（`© Freedom Systems Inc.`）與頁碼。**做任何新報告，優先從這裡挑 layout**，
   不要手刻文字框/顏色。用 `deck_utils.list_layouts()` 印出完整清單與每個 layout 的
   placeholder idx。

2. **檔案本身既有的 6 頁投影片**：這些不是空白版型，是已經畫好內容的成品頁，且部分是唯一沒有
   對應 layout 資產的東西（例如圖示庫），要用複製/挪用的方式取用：

   | index (0-based) | 內容 | 用途 |
   |---|---|---|
   | 0 | 封面（標題投影片 layout） | 直接改標題/副標題文字即可當作新報告封面 |
   | 1 | 標題及內容 layout 的空白示範頁 | 可直接當一般內容頁用，或改用 layout[1] 生新頁效果相同 |
   | 2 | 公司介紹頁「讓自由系統陪伴您成長…IT is not an issue, call us!」| 若報告需要附上公司介紹/結尾頁，直接複製這頁（`duplicate_slide`），不要重畫 |
   | 3 | **圖示庫**：上百個可重複使用的 IT/網路圖示（伺服器、防火牆、AD伺服器、NAS、Switch、無線基地台、資料中心…皆有中文標籤，含「實心可改填滿色」與「空心可改外框色」兩種版本），另有圖示庫已在這頁中示範怎麼標示用法 | **畫任何架構圖 / 拓樸圖時的圖示來源**。用 `deck_utils.list_slides()` 找到目標圖示的 `shape_id`，再用 `copy_shape()` 複製到你新增的空白圖表頁上，不要自己重畫圖示 |
   | 4 | 網路拓樸範例圖 1（辦公室內網：PC/伺服器/防火牆/交換器/無線基地台組成的完整拓樸） | 畫類似架構圖時的排版參考，或直接 `duplicate_slide()` 後只替換其中的設備/文字 |
   | 5 | 網路拓樸範例圖 2（總部—分公司—雲端／SD-WAN 連線示意） | 同上，適合多據點連線示意圖的排版參考 |

## 常用 layout 名稱（節錄，完整清單用 `list_layouts()`）

- `標題投影片` — 封面（idx 0=標題, 1=副標題）
- `標題及內容` — 最常用的一般內容頁（idx 0=標題, 1=內容, 11=頁尾, 12=頁碼）
- `章節標題` / `1_章節標題` / `2_章節標題` / `3_章節標題` — 分節扉頁
- `兩個內容` — 左右各一個內容區塊，適合對照兩個方案/前後對比
- `比較` — 兩欄各含小標＋內容，適合並列比較表
- `只有標題` — 只有大標題，適合放整頁圖表/截圖再自己貼圖片
- `空白` / `1_空白` / `2_空白` / `3_空白` — 幾乎全空，只有頁尾/頁碼，畫架構圖或自訂版面時用這個當底

## 交付前務必做的事

- 若最終報告用不到圖示庫（index 3）或某個範例拓樸圖（index 4/5），記得用
  `deck_utils.delete_slide()` 移除，不要把工具素材頁留在客戶交付版裡。
- 封面（index 0）與公司介紹頁（index 2）的文字如果沿用舊版留下的客戶名稱／日期，記得覆蓋掉，
  避免把上一個專案的資訊帶到新報告。
